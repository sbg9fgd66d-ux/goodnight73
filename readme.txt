这是生日礼物
里面有一些讲给你听的故事和碎碎念,睡不着的时候点开听听。

怎么装

1. 在 iPhone 上用 Safari 浏览器 打开这个链接(不要在微信里打开):

https://sbg9fgd66d-ux.github.io/goodnight73/

2. 点屏幕底部中间的 分享按钮(一个方框加向上的箭头)。

3. 菜单往下滑,找到 「添加到主屏幕」,点它,再点右上角的 「添加」。

4. 好了。桌面上会多一个「晚安」的图标,以后直接点它打开,像普通 app 一样。

提示

· 第一次打开时在有网的地方把两个分类都点开听几秒,之后没有网也能听。
· 播放的时候可以设睡眠定时,到时间会自己停下
· 无聊的时候:点点屏幕,会有萤火虫;快速来回滑动屏幕有惊喜。

晚安,做个好梦。
